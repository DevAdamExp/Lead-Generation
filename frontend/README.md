# LeadGen frontend

The Next.js app for LeadGen: start a search, follow the pipeline live, and browse, filter and export the results.

```bash
cp .env.example .env.local   # points the app at the API on :8000
npm install
npm run dev                  # http://localhost:3000
npm test                     # Vitest + Testing Library
```

See the [main README](../README.md) for running the backend.
